Nutri

View on GitHub →

Grocery price tracker and recipe manager

SvelteKit · TypeScript · Supabase · PostgreSQL · Docker

A full-stack app for tracking grocery prices and managing recipes. Users can compare what a recipe needs against what's on their list, and missing ingredients are added to their shopping list automatically.

  • Built on SvelteKit and Supabase (PostgreSQL), containerized with Docker and deployed to Cloudflare.
  • Row Level Security and JWT-based auth through Supabase ensure users only see and change their own data.
  • Server-side pagination in the data ingestion pipeline keeps large product catalogs fast and light on memory.
  • Normalized relational schema with many-to-many ingredient relationships and quantity tracking.
